An evidence-first Agent Skill

Understand how it works.
Yoink what transfers.

Give your agent a link or a question. Get back what the evidence supports, what fits your situation, and what—if anything—is worth borrowing.

You

Here’s a repository. Does it help this project? What should we borrow, try, track, or reject?

Two ways in

01

Assess this

A repository, paper, product, practice, or claim. Yoinker checks the original artifact and the local reality before recommending adoption.

02

Explain this

A tool, technique, comparison, or open question. Yoinker separates what is observed, claimed, inferred, and still unknown.

One artifact, four possible decisions

Borrow

The mechanism fits and can be reproduced without importing the source wholesale.

Try

A bounded same-task test can resolve the important uncertainty.

Track

A named missing fact or future event would change the decision.

Reject

It conflicts, duplicates, lacks evidence, or costs more than it can return.

What it keeps straight
  • A mention is a lead. The original artifact is evidence.
  • Authority belongs to a claim. Not to a universal source score.
  • A useful part is not a wholesale yes. Fit is decided per mechanism.
  • A recommendation is not permission. Implementation remains a human decision.

Status

Small on purpose.

Version 0.1.0 is the initial MIT-licensed release: one skill, two mode references, one optional brief, and a behavioral evaluation protocol. Structural checks pass. The held-out comparison is still planned, so public availability is not presented as evidence of improved outcomes.
